API リファレンス
=================

次の名前は :mod:`fxtensor_bayesnet` から import します。
``fxtensor_bayesnet.__version__`` はインストールされているバージョン文字列です。
このページの docstring はソースの日本語です。英語版のビルドでは同じ API を英語で表示します。
動作は同じです。

- :class:`fxtensor_bayesnet.ConfigError`
- :func:`fxtensor_bayesnet.load_config`
- :func:`fxtensor_bayesnet.validate`
- :func:`fxtensor_bayesnet.topo_order`
- :func:`fxtensor_bayesnet.config_hash`
- :func:`fxtensor_bayesnet.dump_config`
- :func:`fxtensor_bayesnet.run`
- :class:`fxtensor_bayesnet.Engine`
- :class:`fxtensor_bayesnet.Net`
- :func:`fxtensor_bayesnet.do_config`
- :func:`fxtensor_bayesnet.to_english_keys`

:mod:`fxtensor_bayesnet.plot` は matplotlib が必要です。
モジュールの import だけでは matplotlib を読みません。図を描くときに読みます。
